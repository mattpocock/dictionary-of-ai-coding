Tudo ao redor do [modelo](./Modelo.md) que o transforma em um [agente](./Agente.md): [ferramentas](./Ferramenta.md), [prompt de sistema](./Prompt%20de%20sistema.md), [gerenciamento da janela de contexto](./Janela%20de%20contexto.md), permissões, hooks. **Claude.ai** e **Claude Code** rodam no mesmo modelo mas se comportam diferentemente porque seus harnesses diferem.

_Uso:_

"Mesmo modelo, por que Claude Code está editando arquivos e Claude.ai apenas respondendo perguntas?"

"Harnesses diferentes — Claude Code tem ferramentas de [sistema de arquivos](./Sistema%20de%20arquivos.md), um prompt de sistema diferente e uma camada de permissões. O modelo não é a variável aqui."
