Os números dentro de um [modelo](./Modelo.md) — frequentemente bilhões deles — ajustados durante o [treinamento](./Treinamento.md). Tudo que o modelo "sabe" vive neles. O treinamento os define; a [inferência](./Inferência.md) os usa sem alteração. Também chamados _pesos_ (weights).

_Uso:_

"Podemos fazer fine-tuning dele na nossa base de código?"

"Isso atualizaria os parâmetros — modelo diferente depois. Para um projeto, quase sempre é mais barato carregar a base de código como [contexto](./Contexto.md) do que retreinar."
