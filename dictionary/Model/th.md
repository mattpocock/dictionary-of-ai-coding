term: Model
description: ชุดพารามิเตอร์ ทำงานแบบ Stateless คาดเดา token ถัดไปเท่านั้น ไม่สามารถดำเนินการใดๆ เองได้หากไม่มีระบบควบคุม (harness)
---

ชุด [parameters](./Parameters.md) ที่ทำงานแบบ [Stateless](./Stateless.md) (ไม่มีการจำสถานะ) โดยหน้าที่ของมันมีเพียงการทำ [next-token prediction](./Next-token%20prediction.md) (คาดเดา token ถัดไป) เท่านั้นและไม่ทำอย่างอื่นเลย โมเดลอย่าง "Claude Opus 4.x" และ "GPT-5.x" ถือเป็น model โดยลำพังตัวมันเองแล้ว model ไม่สามารถดำเนินการหรือคิดตัดสินใจใดๆ เองได้ มันจำเป็นต้องถูกควบคุมและจัดลำดับงานผ่านระบบที่เรียกว่า [harness](./Harness.md)

model ไม่สามารถอ่านไฟล์, รันคำสั่ง, ท่องเว็บ หรือจำเรื่องราวเมื่อวานนี้ได้ สิ่งที่มันทำคือรับ [token](./Token.md) เข้าไปและคาดเดา token ส่งกลับออกมา โดยทำงานหนึ่งครั้งต่อหนึ่ง [model provider request](./Model%20provider%20request.md) ดังนั้น ทุกอย่างที่ทำให้เราชวนรู้สึกว่ามี [agent](./Agent.md) กำลังทำงานอยู่ ไม่ว่าจะเป็นการเลือกใช้ [tools](./Tool.md), การอ่านผลลัพธ์ หรือการวนลูปจนกว่างานจะเสร็จ ล้วนเป็นฝีมือของตัว harness ที่เข้ามาจัดระเบียบและสั่งการให้เกิดการคาดเดาเหล่านั้นต่อเนื่องกัน

[Model providers](./Model%20provider.md) (ผู้ให้บริการโมเดล) มักจะปล่อยโมเดลออกมาเป็นระดับ (tier) ตั้งแต่โมเดลขนาดใหญ่ที่ฉลาดที่สุดแต่ทำงานช้าและมีราคาแพง ไปจนถึงโมเดลขนาดเล็กที่เร็วกว่าและถูกกว่าแต่มีความสามารถน้อยกว่า การเลือก tier จึงเป็นเรื่องสำคัญที่คุณต้องตัดสินใจจริง เช่น เลือกใช้โมเดลรุ่นใหญ่เพื่องานวางแผนและการทำดีบั๊กที่ยากๆ และเลือกใช้รุ่นเล็กเพื่องานแก้ไขเชิงกลไกทั่วไป ซึ่งระบบ harness จะช่วยให้คุณสลับรุ่นโมเดลได้ในระหว่าง [session](./Session.md)

การแยกแยะและใช้คำว่า model อย่างเคร่งครัดจะช่วยให้เราหาสาเหตุของปัญหาได้แม่นยำขึ้น ข้อสรุปที่ว่า "model ทำงานนี้ได้แย่" เป็นข้ออ้างที่เฉพาะเจาะจงมาก เพราะ model เดียวกันเมื่ออยู่ใน harness คนละตัว หรือได้รับ [บริบท](./Context.md) ที่ต่างไป มักจะแสดงพฤติกรรมออกมาต่างกันโดยสิ้นเชิง ดังนั้นก่อนจะโทษว่าเป็นเพราะ model ให้ตรวจสอบสิ่งที่เราป้อนให้มันก่อน เพราะผลลัพธ์ที่น่าผิดหวังส่วนใหญ่มักมีสาเหตุมาจากบริบทหรือตัว harness ไม่ใช่ตัว parameters

_ตัวอย่างการใช้งาน:_

"ขั้นตอนการวางแผนนี่ เราควรสลับ model จาก Sonnet เป็น Opus ดีไหม"

"ลองดูได้นะ แต่จริงๆ งานนี้ระบบ harness เป็นตัวแบกหลักเลย ต่อให้เปลี่ยน model ก็อาจจะไม่ช่วยอะไรถ้า [system prompt](./System%20prompt.md) กับ tools ที่เตรียมไว้มันยังไม่ถูก"
