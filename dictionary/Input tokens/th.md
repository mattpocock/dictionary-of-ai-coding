---

จำนวน [token](./Token.md) ที่ระบบควบคุม ([harness](./Harness.md)) จัดส่งไปให้ทางฝั่งผู้ให้บริการในทุก ๆ [model provider request](./Model%20provider%20request.md) ซึ่งครอบคลุมตั้งแต่ตัว [system prompt](./System%20prompt.md) ประวัติการพูดคุยทั้งหมด และ [tool results](./Tool%20result.md) (ผลลัพธ์จากเครื่องมือต่าง ๆ) สรุปง่าย ๆ คือทุกสิ่งทุกอย่างที่ตัว [model](./Model.md) ต้องเปิดอ่านและทำความเข้าใจก่อนที่จะเริ่มลงมือเขียนคำตอบ โดยปกติแล้วโทเค็นขาเข้าเหล่านี้จะมีราคาเรียกเก็บที่ถูกกว่า [output tokens](./Output%20tokens.md) เนื่องจากใช้ทรัพยากรคอมพิวเตอร์ในการประมวลผลฝั่งผู้ให้บริการน้อยกว่า

ในงานเขียนโค้ดร่วมกับ [AI](./AI.md) ค่า input tokens จะกลายเป็นค่าใช้จ่ายส่วนใหญ่ในบิลของคุณ เนื่องจากตัวโมเดลทำงานแบบ [stateless](./Stateless.md) (ไม่มีการจำสถานะ) ในทุก ๆ รอบสนทนา ([turn](./Turn.md)) ระบบจึงจำเป็นต้องหอบเอาประวัติการใช้งานของทั้ง [session](./Session.md) ส่งกลับไปเป็นข้อมูลขาเข้าใหม่เสมอ ตั้งแต่ข้อความแรกสุดที่คุณพิมพ์ คำตอบทุกข้อความของระบบ ไปจนถึงผลลัพธ์ของเครื่องมือทุกชิ้นที่เคยเรียกใช้มา ข้อมูลขาเข้าใน turn ที่ 50 จึงประกอบไปด้วยเนื้อหาทั้งหมดของ 49 turn ก่อนหน้า การส่งคำขอในบาง request อาจจะผลิตเนื้อหาตอบกลับมาเพียงไม่กี่ร้อย output tokens แต่เบื้องหลังอาจต้องส่งข้อมูลประวัติสะสมย้อนหลังกลับไปสูงถึงหลักแสนโทเค็นเลยทีเดียว

ระบบบันทึกส่วนหัวล่วงหน้า ([prefix cache](./Prefix%20cache.md)) จึงถูกนำเข้ามาช่วยลดภาระค่าใช้จ่ายในจุดนี้ โดยประวัติข้อความส่วนที่ตรงกับ request ก่อนหน้าแบบเป๊ะ ๆ จะถูกคำนวณราคาเป็นโทเค็นส่วนแคชแทนราคาข้อมูลขาเข้าแบบเต็มเม็ดเต็มหน่วยอย่างมาก แต่ถ้าหากค่าใช้จ่ายฝั่งขาเข้ารวม ๆ แล้วยังคงสูงเกินไป วิธีแก้ไขคือต้องพยายามลดขนาดของข้อมูลที่จะถูกส่งซ้ำ เช่น การสั่งล้างประวัติการคุย หรือการสั่งบีบอัดสรุปใจความ[บริบท](./Context.md)เมื่อคุณสลับไปเริ่มทำงานชิ้นใหม่

_ตัวอย่างการใช้งาน:_

"บิลค่าบริการเดือนนี้แพงมากเลย ทั้งที่ตัว [agent](./Agent.md) แทบจะไม่ค่อยเขียนโค้ดอะไรยาว ๆ ส่งกลับมาให้เลยนะ"

"เป็นเพราะค่า input tokens ครับ เพราะในทุก ๆ turn ระบบจะต้องหอบเอาประวัติข้อมูลของทั้ง session ส่งกลับไปใหม่ทั้งหมด ถ้าไม่มีระบบ prefix cache คอยช่วย คุณก็ต้องจ่ายเงินค่าประวัติย้อนหลังเหล่านั้นเต็มราคาใหม่ในทุก ๆ request เลยล่ะครับ"
